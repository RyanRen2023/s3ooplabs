## Description
This lab demonstrates the implementation of the DAO (Data Access Object) pattern in Java. The project includes classes for managing database connections, performing CRUD operations on entities such as courses, students, and student courses, as well as generating reports.

## Project Structure

### Packages
- `dao`: Contains DAO classes and interfaces.
- `dto`: Contains Data Transfer Object (DTO) classes.
- `utility`: Contains utility classes.
- `report`: Contains report generation classes.
